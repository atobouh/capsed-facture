1. Installer CAPSED Bureau

1

Télécharger

Sur l’ordinateur du bureau, ouvrez ce lien : CAPSED-Bureau-installation.exe (environ 4 Mo). Ouvrez le fichier téléchargé.

2

Si Windows affiche « Windows a protégé votre ordinateur »

C’est normal : l’application est un outil interne, sans certificat payant. Cliquez Informations complémentaires 1, puis Exécuter quand même 2.

« Exécuter quand même » n’apparaît qu’après avoir cliqué « Informations complémentaires ».

3

Ouvrir CAPSED Bureau

L’installation est rapide. Une icône violette avec un triangle blanc apparaît sur le bureau et dans le menu Démarrer. À chaque ouverture, une petite carte « Ouverture… » s’affiche tout de suite, puis l’application.

Si l’ordinateur n’a pas le composant Microsoft WebView2L’installation le télécharge : il faut alors internet pendant l’installation. Windows 10 et 11 l’ont presque toujours.

2. Relier l’ordinateur (une seule fois)

1

Demander un code à la Direction

La Direction ouvre son site : Réglages, Équipe et accès, Relier un ordinateur. Un code à 6 chiffres s’affiche (voir Direction : relier un ordinateur).

2

Taper le code sur l’ordinateur du bureau

Tapez le code 1, donnez un nom à l’ordinateur 2 (par exemple « Facturation 1 » ou « Accueil »), puis Relier l’ordinateur 3.

Le code n’est valable que 24 heures, et une seule fois.Ce n’est que le code qui expire. Une fois l’ordinateur relié, il le reste : rien à renouveler. Un code non utilisé à temps : la Direction en crée simplement un autre.
Connexion très lente ?Le bouton affiche « Connexion lente, on continue… » et l’application réessaie toute seule. Si la réponse se perd en route, réessayer avec le même code fonctionne : l’ordinateur n’est jamais relié deux fois.
3

Première récupération des données

L’ordinateur reçoit les clients, les factures et les comptes de l’équipe. Le nombre d’éléments reçus s’affiche. C’est la seule étape qui a besoin d’internet ; ensuite, l’ordinateur travaille même sans.

3. Se connecter

Chaque personne tape l’identifiant 1 et le mot de passe 2 donnés par la Direction, puis Se connecter 3. Le mot de passe est vérifié sur l’ordinateur : ça marche sans internet.

Chacun ne voit que ses onglets : la Facturation voit Factures, Clients, Demandes ; l’Encaissement voit Clients et paiements, Demandes ; « Facturation et encaissement » voit tout.

4. La barre d’état : tout est-il envoyé ?

En bas à gauche 1, l’application dit où en sont les envois :

  • Tout est envoyé · 14:32 : le cloud et la Direction ont tout.
  • 2 modifications en attente : elles partiront dès que la connexion revient. Rien n’est perdu, continuez à travailler.

5. Verrouiller, se déconnecter

  • Verrouiller (Verrouiller ou Ctrl+L) : pour une pause. Le travail en cours reste à l’écran, caché. Seul votre mot de passe le rouvre 1.
  • Verrouillage automatique : après 10 minutes sans toucher l’ordinateur.
  • Ce n’est pas moi : changer d’utilisateur 2 : quelqu’un d’autre prend le poste ; il se connecte avec son propre compte.
  • Se déconnecter : en fin de journée, ou en laissant le poste à un collègue.

6. Les mises à jour se font toutes seules

CAPSED Bureau vérifie en arrière-plan s’il existe une nouvelle version, la télécharge et la contrôle. Un message apparaît : « Nouvelle version 1.0.x prête. Elle s’installe quand vous fermez CAPSED Bureau. »

  • Vous ne faites rien : elle s’installe à la fermeture de l’application. À la prochaine ouverture, c’est la nouvelle version.
  • Ou Installer maintenant : un écran violet « Mise à jour de CAPSED Bureau » s’affiche, l’application se ferme, une petite fenêtre d’installation apparaît, puis CAPSED Bureau se rouvre tout seul (moins d’une minute).

Une mise à jour n’arrive que lorsque la Direction (ou le développeur, avec son accord) la publie pour l’équipe. Le message peut dire ce qui change (« Nouveautés : … »).

« La mise à jour … ne s’est pas installée la dernière fois »Cliquez Réessayer. Si cela ne marche toujours pas : téléchargez l’installateur (lien en haut de cette page), ouvrez-le, puis rouvrez CAPSED Bureau. Les données ne sont pas touchées.
Les données ne sont pas touchées.Les factures, paiements et modifications en attente restent sur l’ordinateur et dans le cloud.

7. Si l’ordinateur a été retiré

Quand la Direction retire un ordinateur (perdu, remplacé…), il déconnecte la personne dès qu’il a internet et affiche « Cet ordinateur a été retiré par la Direction ». Pour l’utiliser de nouveau : un nouveau code de la Direction.

8. Remplacer un ordinateur

  1. Sur l’ancien ordinateur, s’il marche encore : vérifiez « Tout est envoyé ».
  2. Installez CAPSED Bureau sur le nouveau et reliez-le avec un nouveau code.
  3. La Direction retire l’ancien (Réglages, Équipe et accès, Ordinateurs du bureau, Retirer).

Le nouvel ordinateur reçoit tout l’historique depuis le cloud.
